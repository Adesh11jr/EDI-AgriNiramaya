Last updated: October 2026 • First-Year Engineering EDI Project

1. Academic Demonstration Project

AgriNiramaya is developed as a First-Year Engineering Design & Innovation (EDI) project. It is intended for educational demonstration, agronomic research prototyping, and IoT telemetry experimentation.

2. Agricultural Advisory Disclaimer

The soil health recommendations, pH adjustments, and disease diagnostics provided by the platform are generated using standard agronomic benchmarks (FAO/USDA guidelines). While designed to be technically accurate, they should supplement, rather than replace, on-field consultation with certified government agricultural extension officers.

3. User Account Responsibilities

Users are responsible for safeguarding their login credentials and ensuring that telemetry transmitted by external microcontrollers adheres to the specified JSON payload formats.

4. Intellectual Property & Open Architecture

The modular software architecture, frontend templates, Flask backend routes, and database schemas are created for academic demonstration. Unauthorized malicious penetration or denial-of-service testing against demonstration servers is prohibited.

5. Revisions & Updates

The project developers reserve the right to refine endpoints, update soil classification parameters, or integrate machine learning weight models in accordance with project milestone schedules.
