AgriNiramaya: System Architecture & Design

AI-Enabled Integrated Plant Health and Soil Monitoring System
First-Year Engineering Design & Innovation (EDI) Project

Problem Statement & Engineering Motivation

Agriculture is the cornerstone of food security and rural livelihoods. However, smallholder and commercial farmers face recurring yield reductions caused by late foliar disease diagnosis, erratic rainfall, and uncalibrated chemical soil treatments. Traditional soil testing requires lab dispatch cycles taking days or weeks, while foliar pathogens often spread across an entire field within 48 to 72 hours under humid conditions.

AgriNiramaya bridges this gap by delivering an integrated, edge-to-cloud agricultural monitoring ecosystem. Combining low-power ESP32 IoT sensor telemetry with responsive web dashboards and modular AI image inspection pipelines, AgriNiramaya empowers farmers to practice scientific precision agriculture without prohibitive capital investment.

Technical Blueprint

End-to-End System Architecture

01

Physical IoT Layer

ESP32 microcontrollers deployed in fields. Connected to capacitive soil moisture sensors, analog pH electrodes, and DHT22 digital micro-climate sensors.

02

RESTful Flask Backend

Python Flask server operating on port 5000. Implements REST APIs for authentication, farm management, sensor ingestion, and leaf inspection.

03

Persistent Relational Data

Robust SQLite database (plant_doctor.db) with foreign keys, indexes, and user ownership for farms, telemetry, and uploads.

04

Responsive SaaS Frontend

Clean HTML5, CSS3, and Vanilla JavaScript design system. Fully responsive across smartphones, tablets, and desktop workstations.

Academic Course & Demonstration Details
