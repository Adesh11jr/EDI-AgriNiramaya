AI Model Architecture Ready

In strict adherence to academic evaluation guidelines, AgriNiramaya never fabricates random or synthetic AI prediction confidence scores.

• Images are securely validated, saved with UUIDs, and indexed in SQLite.
• When a trained Convolutional Neural Network (CNN) weights file (e.g. MobileNet / ResNet .h5 or .onnx) is placed in flask_project/weights/, automated model inference executes seamlessly.
• When weights are pending, the diagnostic profile provides verified agronomic reference criteria for the selected crop.

Inspection Best Practices

  • Capture photograph in natural morning light
  • Avoid extreme blur or direct harsh sunlight reflection
  • Frame single leaf showing both diseased margins and green tissue
